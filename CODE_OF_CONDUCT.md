# Code Of Conduct

Zova should be a calm, useful place to work on database software.

## Expected Behavior

- Be respectful and direct.
- Assume good intent, but accept corrections.
- Keep criticism focused on the code, design, docs, or behavior.
- Explain tradeoffs clearly.
- Make room for people with different experience levels.

## Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Discriminatory language or behavior.
- Sexualized language or attention.
- Publishing private information without permission.
- Repeatedly derailing issues or pull requests after maintainers ask you to
  stop.

## Scope

This applies to Zova project spaces, including GitHub issues, pull requests,
discussions, release comments, and project-related communication.

## Enforcement

Maintainers may edit, hide, or delete comments; close issues or pull requests;
or block users from participating when behavior harms the project or other
contributors.

If you need to report a conduct problem, contact the maintainer privately
through GitHub.
